# Documentación visual — Bloom

Espacio para recopilar referencias de diseño, branding y experiencia de usuario **antes** de construir la interfaz en React.

No incluye código de frontend: solo imágenes, capturas, notas y guías visuales.

## Estructura de carpetas

| Carpeta | Para qué sirve |
|---------|----------------|
| [`moodboard/`](moodboard/) | Inspiración general: atmósfera, fotografía, ilustración, apps de referencia y sensación visual de la marca. |
| [`login/`](login/) | Referencias de pantallas de inicio de sesión: layout, formularios, mensajes de error y estados vacíos. |
| [`register/`](register/) | Referencias del registro: campos, flujo, validación visual y bienvenida tras crear cuenta. |
| [`feed/`](feed/) | Referencias del muro principal: tarjetas de post, likes, comentarios, filtros y jerarquía de contenido. |
| [`profile/`](profile/) | Referencias de perfil de usuaria: avatar, historia, datos de ubicación y edición de perfil. |
| [`community/`](community/) | Referencias de comunidad y descubrimiento: recursos votados, apoyo entre pares y listados por contexto. |
| [`colors/`](colors/) | Muestras de color, paletas exportadas, contrastes y pruebas de accesibilidad. |
| [`design-system/`](design-system/) | Guía central: visión, valores, tipografía, componentes base y reglas que unifican todas las pantallas. |

## Cómo usar esta carpeta

1. Guarda capturas o exports en la carpeta que corresponda a la pantalla o tema.
2. Nombra los archivos de forma clara, por ejemplo: `feed-cards-referencia-01.png`.
3. Actualiza [`design-system/README.md`](design-system/README.md) cuando fijes decisiones de color o tipografía.
4. Consulta esta documentación al iniciar el Sprint 3 (frontend).
